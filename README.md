# 清屏 · 拦开屏广告（vivo / OriginOS 可用）

一个纯原生、零第三方依赖、零联网的安卓小工具：靠「无障碍服务」读取当前窗口，
自动点掉「跳过广告 / 关闭广告」按钮，并按 App 统计拦截次数，在软件里查看。

> 本机（跑 DSH 的这台 Windows）没有 JDK / Android SDK / Gradle，编不出 APK，
> 所以走 GitHub Actions 云端编译，编好直接给你一个能装的 APK。

---

## 一、拿到 APK（在电脑网页上做，约 5 分钟，不用装任何软件）

1. 打开 https://github.com/new 新建一个仓库，名字随便（如 `qingscreen`），
   选 **Public**，**不要**勾选 "Add a README file"（空仓库最省事），点 Create。
2. 把本压缩包解压，进到 `qingscreen` 文件夹，**全选里面所有文件**（含 `.github` 文件夹），
   拖到 GitHub 仓库页面中间的 "uploading files" 区域；
   或者点 **Add file → Upload files** 把文件拖进去。
   提交说明随便填，点 **Commit changes**。
3. 点仓库顶部的 **Actions** 标签 → 左边选「编译清屏 APK」→
   如果没自动跑，点右边 **Run workflow** 手动跑一次。等 3～6 分钟变绿 ✅。
4. 进这次成功的运行记录，最下面 **Artifacts** 里点 **qingscreen-apk** 下载（是个 zip），
   解压出 `app-debug.apk`。
5. 把这个 APK 传到手机（QQ / 数据线都行），点开安装。
   vivo 会提示「未知来源」，允许一次即可。

> debug 版已自带签名，能直接装；不用自己配密钥。

---

## 二、装完后必做的权限（这些系统不让静默开，只能你亲手点）

打开「清屏」App，按界面上 4 个按钮依次点：

1. **① 无障碍服务（必开）**：跳到系统设置 → 无障碍 → 已安装的服务 → 找到「清屏」→ 打开。
   这是拦截的核心，不开就完全不工作。
2. **② 关闭电池优化**：点按钮后选「允许 / 不优化」。
3. **③ 自启动与后台锁定（vivo i管家）**：按钮会尝试直接跳 i管家；
   若没跳过去，手动开：i管家 → 应用管理 → 权限管理 → 自启动 → 允许「清屏」；
   再进「后台高耗电 / 后台锁定」把「清屏」加白名单。
4. **④ 通知权限**：Android 13+ 会弹一次，允许（前台常驻通知要靠它保活）。

弄完回 App，顶部显示「无障碍服务：✅ 已开启」就成了。
以后打开带开屏广告的 App，广告会被自动点掉，统计页按 App 累加次数。

## 三、能实现 / 受系统限制（丑话）

**能实现**
- 自动点击「跳过广告 / 关闭广告」文本按钮，覆盖绝大多数用原生控件画广告的 App ✅
- 按 App 统计拦截次数，软件内查看今日 / 累计 ✅（数据只存本机，不联网不上传）
- 开机自启前台常驻、START_STICKY 兜底尽量抗清理 ✅
- 本地 VPN / DNS 过滤作为补充思路（本版未内置，避免引入复杂权限）

**受系统限制，做不到 100%**
- 「清理后台后 100% 不失效」不可能：国产 ROM 杀进程是系统行为，只能靠
  前台常驻 + 忽略电池优化 + 自启动白名单 + 锁定后台尽量撑住，被强杀后靠开机广播/常驻通知拉回。
- 无障碍服务**必须用户手动开**，任何 App 都不能静默开启。
- 广告是「先出现、再被点掉」，所以仍可能闪一下；做不到「根本不显示」。
- 自绘 / SurfaceView / Flutter / Unity / FLAG_SECURE 的页面拿不到控件树，
  只能靠坐标盲点（本版为稳妥未做，避免误触）；摇一摇跳转靠传感器，难根治。
- Android 10+ 禁止后台弹界面；规则词表需要随 App 更新维护。
- Google Play 对「自动点广告」类应用政策敏感，所以走 GitHub / 自行分发。

## 四、技术栈 / 结构

- Java 17 · Android Gradle Plugin 8.7.3 · compileSdk 34 · minSdk 26 · targetSdk 33
- 纯 Android 原生 API，无 AndroidX / 无第三方库 → 云端一次编译通过率最高
- `ClearAccessibilityService`：监听窗口变化，递归找跳过词并点击
- `StatsStore`：SharedPreferences 按包名存次数
- `KeepAliveService`：前台常驻通知保活
- `BootReceiver`：开机拉起
- `MainActivity`：代码布局的权限引导 + 统计列表

仅用于拦截本人设备上的开屏广告，不破解、不联网、不收集任何数据。
